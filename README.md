# 📊 PhonePe Data Analysis & Visualization

## 🚀 Project Overview

This project performs an in-depth Exploratory Data Analysis (EDA) on PhonePe digital payment data to uncover transaction trends, user behavior, and regional performance across India.

The dataset is extracted from the official PhonePe Pulse GitHub repository and processed using Python to generate meaningful insights through data visualization.

---

## 🎯 Business Objectives

* Identify top-performing states and regions
* Understand transaction patterns and user behavior
* Analyze growth trends in digital payments
* Detect seasonal variations in transactions
* Provide data-driven recommendations

---

## 📂 Dataset

📌 Source: https://github.com/PhonePe/pulse

The dataset contains:

* Aggregated transaction data
* Map-based insights
* Top-performing states/districts

---

## 🛠️ Tech Stack

* 🐍 Python
* 📊 Pandas & NumPy
* 📈 Matplotlib & Seaborn
* ☁️ Google Colab

---

## 📊 Key Visualizations

* Top States by Transaction Amount
* Transaction Type Distribution
* Yearly Growth Trends
* Quarterly Analysis
* Correlation Heatmap
* Pair Plot Analysis

---

## 🔍 Key Insights

* 📈 Rapid growth in digital payments over the years
* 🏆 Maharashtra, Karnataka, and Telangana are top-performing states
* 💸 Peer-to-peer and merchant payments dominate usage
* 📅 Higher transaction activity observed in later quarters
* 🔗 Strong correlation between transaction count and transaction amount

---

## 💼 Business Recommendations

* Focus on high-performing regions for maximum ROI
