# 📊 PhonePe Data Analysis Project

## 📌 Project Overview

This project analyzes PhonePe digital payment data to understand transaction patterns, user behavior, and regional performance across India.

---

## 🎯 Objectives

* Identify top-performing states
* Analyze transaction types
* Study growth trends
* Understand user behavior

---

## 📂 Dataset Source

https://github.com/PhonePe/pulse

---

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

---

## 📊 Key Insights

* Digital payments are growing rapidly
* Maharashtra, Karnataka are top states
* Peer-to-peer transactions dominate
* Strong correlation between count & amount

---

## 🚀 Conclusion

This project helps understand digital payment trends and provides insights for business growth.
